# Psyxoz — Unity Developer

I develop gameplay and graphics tools in C#, HLSL and C++. My work spans mobile games, Unity Editor tooling, GPU rendering and asset pipelines.

## Personal projects

- Real-time DXR path tracing in Unity URP, with OpenPBR and a native Streamline bridge. [Lucent Path](https://github.com/Psyxoz13/LucentPath)
- Subpixel strand rendering, GPU hair simulation and grooming tools for Unity URP. [HairLines](https://github.com/Psyxoz13/HairLines)
- Audio-driven mouth animation for VRM 1.0, with a Unity timeline generator and editor. [AutoLipsSync](https://github.com/Psyxoz13/AutoLipsSync)
- Texture codec and Unity Addressables integration for device-specific GPU formats. [QTX](https://github.com/Psyxoz13/QTX-Codec) · [UniQTX](https://github.com/Psyxoz13/UniQTX-SDK)
