# Psyxoz — Unity Developer

I develop games for PC and mobile with Unity and C#. Since 2021, I’ve worked on commercial games for Android and iOS. I can take a Unity project through the full development cycle, from prototyping and architecture to gameplay implementation, platform builds, and release.

I design modular gameplay systems and build Unity Editor tools that help teams author levels, prepare assets, and automate repetitive work. My graphics work includes HLSL shaders, compute shaders, and GPU rendering. I use C++ for native integrations.

I profile CPU and GPU performance and memory usage, then use those measurements to tune rendering, assets, and content loading for the target hardware. I work within mobile performance budgets and adapt PC builds to different CPU and GPU configurations.
